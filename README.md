# Royal Road als Buch

Ein Userscript, das Kapitel auf [royalroad.com](https://www.royalroad.com) wie ein Buch darstellt: umblättern statt scrollen, Doppelseite auf breiten Bildschirmen, Serifenschrift, Sepia/Hell/Dunkel, nahtloser Wechsel ins nächste Kapitel und Weiterlesen auf einem anderen Gerät über Royal Roads „Continue Reading“.

## Installation

Einmal pro Gerät diesen Link öffnen, die Erweiterung zeigt dann einen Installationsdialog:

**https://raw.githubusercontent.com/Intertwined4/Royal-Road-als-Buch/main/royalroad-buchmodus.user.js**

| Gerät | Erweiterung |
|---|---|
| Android (Firefox) | Violentmonkey |
| iPad / iPhone (Safari) | Userscripts |
| PC (Chrome, Firefox, Edge) | Tampermonkey oder Violentmonkey |

Updates kommen danach automatisch: Die Erweiterungen prüfen diese Adresse regelmäßig auf eine neue `@version`.

## Bedienung

- Auf einer Kapitelseite unten rechts auf **📖 Buchmodus** tippen (am PC: Taste **B**).
- Blättern: rechts/links tippen, wischen oder ← →. Mitte antippen blendet die Leisten ein und aus.
- Tablet/Handy: kurz nach unten scrollen, dann füllt das Buch den Bildschirm. Kräftig nach unten ziehen führt zurück zum Rand oben.
- Kommst du nach dem Lesen auf einem anderen Gerät zurück, springt der Buchmodus zum dort zuletzt gelesenen Kapitel (mit „Zurück“-Knopf).
